`checkGraphSignature` takes one options object: `checkGraphSignature({ body, headers, appSecret, logger })`. The positional form `(body, headers, appSecret, logger?)` is a deprecated overload with the same results. New types `GraphSignatureOptions` and `GraphWebhookHeaders`. graph-core is public and covered by semver like the other public packages.

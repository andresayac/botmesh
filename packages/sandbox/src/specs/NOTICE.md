# Vendored OpenAPI fragments

`twilio.ts` and `discord.ts` are generated by `scripts/vendor-openapi.mjs` from
the official OpenAPI documents below. Only the request bodies of the endpoints
the providers call are kept (descriptions and vendor extensions removed). The
tests never fetch anything; to refresh, download the two files and run the
script with their paths and commit SHAs.

| File | Source | Commit |
| --- | --- | --- |
| `twilio.ts` | <https://github.com/twilio/twilio-oai> `spec/json/twilio_api_v2010.json` (`CreateMessageRequest`) | `157fb094bd08957183278242d7622c8560b7a4c4` |
| `discord.ts` | <https://github.com/discord/discord-api-spec> `specs/openapi.json` (`MessageCreateRequest`, `MessageEditRequest`, webhook execute) | `bf93257f85d62054a0a6982d32f6bcb724abd015` |

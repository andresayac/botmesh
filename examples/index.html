Examples ​

Complete bots you can copy, run and adapt. Most examples are one bot.js file that shows a set of botmesh features, with a transcript captured from a real run and links to the guide of every feature it uses. A test runs every example's code and checks its transcript, so what you read is what you get.

Run any example ​

  1. Set up a project once, as in Getting started (Node.js 22.12+, "type": "module", npm install @botmesh/core @botmesh/baileys).

  2. Save the example's code as bot.js.

  3. Chat with it in the terminal, no phone needed:

    bash
    npx botmesh dev bot.js

  4. Connect it for real with node bot.js (a QR code for WhatsApp), or swap the provider for Telegram. The bot code does not change between channels.

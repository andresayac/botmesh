    Interface PluralForms

    Plural variants of one message, picked with params.count (Intl.PluralRules of the active language). other is required; zero also matches an exact count === 0 even in languages whose rules have no zero category (es, en).

    Example

    { zero: 'Sin artículos', one: '{count} artículo', other: '{count} artículos' }

    Optionalids

    ids?: "hash" | "raw" | "omit"

    How chat, sender and message ids appear on spans:

    • 'hash' (default): HMAC-SHA256 with idKey, base64url, 16 chars;
    • 'raw': the opaque id as the provider gave it (personal data on most channels);
    • 'omit': not recorded.
    • Defined in telemetry/types.ts:144

    OptionalidKey

    idKey?: string | Uint8Array<ArrayBufferLike>

    HMAC key of ids: 'hash'. Default: 32 random bytes per process, so hashes do not correlate across replicas or restarts — set it from a secret for that.

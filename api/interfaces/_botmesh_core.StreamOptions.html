    OptionalonCancel

    onCancel?: "flush" | "discard"

    What to do with the text produced so far on cancellation. Default 'flush' (send it). 'discard' sends nothing more and removes the live preview: a draft simply expires and, with the edit strategy, the message being edited is deleted (when the transport can delete; otherwise only its cursor is removed). Messages already completed before the cancel stay.

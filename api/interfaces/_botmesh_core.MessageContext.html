    Interface MessageContext<TTools, TRaw>

    The ergonomic context handed to every handler. Generic over TRaw. The reply helpers keep IDENTICAL signatures to v1 — internally each now builds an OutboundContent descriptor and calls provider.send, instead of hand-rolling Baileys JSON. from/sender/body/type/isGroup are read straight off the normalized InboundMessage, so user code and keyFor are unchanged.

    • edit(content: string | OutboundContent, opts?: EditOptions): Promise<EditResult>

      Edit this context's own last reply (ctx.edit(content), only when it has the same content kind and no bot.send/bot.sendTo went to the chat since; replies of other handler runs or other participants' flows are never targeted) or a given one (ctx.edit(ref, content); a fallback send goes to ref.chatId).

    OptionalreclaimOwnBefore

    reclaimOwnBefore?: number

    With reclaimOwn: re-claim an own sending record only when its lease ends before this time (epoch ms). A restarted replica's first sweep passes recoveredAt + leaseMs: the leases its dead incarnation took end earlier, the ones it took itself since then end later, so it never steals a send it is making (which would leave that send's completion with a superseded fencing token). A journal that ignores it re-claims every own lease.

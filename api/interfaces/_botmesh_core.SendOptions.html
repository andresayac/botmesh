    OptionalidempotencyKey

    idempotencyKey?: string

    Durability (BotConfig.durability): idempotency key of this send in the outbox. A key that was already sent is answered from the outbox without sending again. Optional — sends made while handling an inbound message get a deterministic key automatically. With durability on, core strips it before calling the provider; with it off, it is passed through and providers ignore it.

    OptionalpreviousPart

    previousPart?: string

    The key of the record that must be sent before this one: set on the later parts of a split text (<key>#2 follows <key>, <key>#3 follows <key>#2…). The sweeper never sends a record while that one is still to be sent, and dead-letters it when that one is dead. A key ending in #<n> chosen by the caller has no such link.

    Interface InboundMessage<TRaw>

    The single normalized inbound message. chatId/senderId are ALREADY stable and resolved — the stability contract (see IProvider) guarantees the same human yields the same senderId (and chat the same chatId) for the session, so ConversationRuntime.keyFor(${chatId}:${senderId}) is safe for ANY conforming provider. Field names from/sender/body/type/isGroup are duplicated to match RuntimeMessage/MessageContext so the object flows into the dispatcher/runtime unchanged.

    ref

    ref: MessageRef

    ref.id MUST be unique per logical inbound message within its chat and stable across redelivery (webhook retry, reconnect replay), or '' when the transport cannot guarantee that. Core dedupes on chatId + ref.id (BotConfig.dedupe, on by default); see the INBOUND ID CONTRACT on IProvider.

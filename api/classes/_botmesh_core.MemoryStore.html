    Class MemoryStore

    The built-in IStore: everything in RAM, optionally saved to a JSON file on an interval and when the bot stops. It is the default store. It keeps the newest 1000 messages per chat unless maxMessagesPerChat says otherwise. For a database, use @botmesh/sqlite-store or @botmesh/redis-store.

    Example

    const bot = new Bot({ provider, store: new MemoryStore({ file: './data/store.json' }) })

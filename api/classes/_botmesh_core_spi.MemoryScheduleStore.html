    • claimDue(
          id: string,
          owner: string,
          now: number,
          leaseMs: number,

      Atomic claim: succeeds only when nextRunAt !== null && nextRunAt <= now and the record has no live lease (leaseUntil absent or <= now). Then it sets leaseOwner = owner, leaseUntil = now + leaseMs and increments fencingToken. Returns null otherwise (not due, leased elsewhere, or unknown id).

    Class FlowBuilder<S>

    Builder returned by flow. Chain steps (say, ask, choose, do, media, form, use, goto…) and register the flow with bot.use(). Every method returns the builder, and the type of c.state grows with each ask, choose and use.

    guard

    • guard(check: FlowGuard<S>, onFail?: GuardFailure<S>): FlowBuilder<S>

      Stop the flow unless check passes. On failure it sends onFail and ends the conversation, or — with { redirect } — jumps to another conversation:

      .guard(() => esHorarioLaboral(), 'Fuera de horario, vuelve mañana')
      .guard(async (ctx) => isAdmin(ctx.sender), { redirect: 'no-permiso' })

    form

    • form(definition: FormDefinition, opts?: FormStepOptions): FlowBuilder<S>

      Collect a typed form. On providers with capabilities.forms === 'native' (WhatsApp Cloud API → WhatsApp Flows) it sends one native form and waits for its submission; elsewhere it asks field by field. Either way the validated answers are stored in c.state[opts.stateKey ?? definition.id]. The definition is checked here: a malformed one throws a TypeError.

      Parameters

      • definition: FormDefinition
      • Optionalopts: FormStepOptions

      Returns FlowBuilder<S>

      Example

      flow('registro')
        .form({ id: 'signup', title: 'Registro', fields: [
          { type: 'text', name: 'name', label: 'Nombre' },
          { type: 'email', name: 'email', label: 'Correo' },
          { type: 'select', name: 'plan', label: 'Plan', options: { basic: 'Básico', pro: 'Pro' } },
        ] })
        .say((_ctx, c) => `Gracias ${(c.state.signup as { name: string }).name}`)

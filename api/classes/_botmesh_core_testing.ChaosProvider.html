    Class ChaosProvider<P>

    An IProvider that wraps another one and delivers its traffic adversarially (see the module docs and ChaosOptions). Pass it to new Bot({ provider }) and keep driving the wrapped provider (chaos.inner.incoming(...)).

    Optional provider capabilities (typing, markRead, downloadMedia, …) are exposed only when the wrapped provider has them, so feature detection in the Bot keeps working.

    Push ingress for webhook transports (Cloud API POST, Telegram/Discord webhook, Discord interaction endpoint). The host HTTP server calls this with the raw body (and, optionally, the request headers for signature checks); the provider normalizes and emits via onEvent.     OptionalserializeMediaRef

    serializeMediaRef?: (ref: MediaRef) => SerializedMediaRef | undefined

    Durable journaling (BotConfig.durability): turn a live MediaRef into a JSON-safe, versioned reference that rehydrateMediaRef can rebuild in another process, so a replayed message (crash recovery, background retry) can still download its media. Synchronous, cheap and side-effect free; a throw counts as "not durable". Return undefined for a ref that must not be journaled (e.g. view-once media). Never include credentials: the result is stored at rest with the inbound record.

    Show (or update) an ephemeral, not-yet-sent preview of a message being generated. Same draftId → the same draft is updated in place. A draft is NOT a message: the caller must still send() the final text. Only for providers with capabilities.streaming === 'draft'; rejects (typed error) where the transport refuses drafts (e.g. Telegram groups), and the caller then falls back to edits or chunks.

    OptionaltextFormatFor

    textFormatFor?: (chatId: string) => TextFormat | undefined

    Rich-text dialect of one chat, for providers that serve several channels with different markup through one instance (e.g. Twilio: whatsapp: chats render WhatsApp markup, SMS chats render none). Return undefined when the chat's format is unknown; the core then falls back to capabilities.textFormat. Exposed as ctx.textFormat. Must be synchronous and cheap (it runs once per inbound message). Absent = every chat uses capabilities.textFormat.

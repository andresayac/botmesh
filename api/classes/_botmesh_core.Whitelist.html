    Class Whitelist

    bot.whitelist — an AccessList plus a mode switch. While disabled (the default) its entries have no effect. While enabled, only messages whose senderId OR chatId is on the list are processed; an enabled, empty whitelist blocks everyone. The blacklist always wins over the whitelist.

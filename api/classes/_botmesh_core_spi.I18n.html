    Class I18n

    The translation engine behind bot.locale(), ctx.t() and ctx.lang: locale catalogues, plural forms, {param} interpolation and language resolution. Exposed for integration authors; applications use the bot methods.

    resolve

    • resolve(ctx: MessageContext): Promise<string>

      Resolve the language of an inbound context: the ctx.user preference → the provider-reported language → the detector's answer → the default. Each candidate only counts when a registered locale serves it (supported), so the result is always a registered locale or the default. Never rejects. Returns the default immediately while i18n is not enabled.

      Parameters

      • ctx: MessageContext

      Returns Promise<string>

    Module @botmesh/core

    @botmesh/core — transport-agnostic bot engine.

    Flows, hooks, plugins, conversations, scheduler and DI. Pair it with a transport provider (@botmesh/baileys for WhatsApp) and, optionally, a store (@botmesh/sqlite-store, @botmesh/redis-store) and the @botmesh/ai plugin.

    This entry exports what an application needs: the Bot, the flow DSL, the message vocabulary, the option types and the errors an app can catch. The other entries:

    • @botmesh/core/testing: test kit (createTestBot, MockProvider, chaos kit, golden transcripts, crash simulation, in-memory coordinators).
    • @botmesh/core/spi: for authors of stores, durability backends, schedule stores, coordinators, tracer integrations and transports (reference backends, record types, key and form helpers).
    • @botmesh/core/dev: the botmesh dev terminal simulator.
    • @botmesh/core/internal: engine building blocks, with no semver guarantee.

    Example

    import { Bot, flow } from '@botmesh/core'
    import { BaileysProvider } from '@botmesh/baileys'

    const bot = new Bot({ provider: new BaileysProvider({ session: 'demo' }) })
    bot.when('hi', (ctx) => ctx.reply('Hello! 👋'))
    await bot.start()

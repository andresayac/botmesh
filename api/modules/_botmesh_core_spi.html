    Module @botmesh/core/spi

    @botmesh/core/spi — the service-provider interface: what authors of backends and transports build on, kept out of the application entry (@botmesh/core).

    • Stores (IStore): the message-key helpers, the checkpoint record types, the user-data rows. Every store runs the shared conformance suite (test-utils/store-conformance.ts).
    • Durability backends (DurabilityBackend): KvDurability over any DurableKv, the reference MemoryKv, the inbox/outbox journal contracts and record types, the retry policy and the errors a backend throws.
    • Schedule stores (ScheduleStore): the record types, the reference MemoryScheduleStore and the claim/complete rules every backend must follow.
    • Leases and coordinators (LeaseProvider, Coordinator): the reference MemoryLeaseProvider and the turn/leadership types.
    • Transports (IProvider): toInboundLocation(), the native-form helpers and the built-in message catalog for texts rendered outside a bot.
    • Tracer integrations (BotTracer): the no-op tracer and the W3C trace-context helpers.
    • Flow interpreters (code that runs declarative steps inside a do, such as @botmesh/flow-schema): the cancellable pause and the form runner of the core interpreter.

    Unlike @botmesh/core/internal, everything here follows semver: a breaking change is a major release of @botmesh/core.

    import { KvDurability, MemoryKv, messageKey } from '@botmesh/core/spi'

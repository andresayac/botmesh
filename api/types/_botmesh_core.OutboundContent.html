    Tagged union of transport-neutral content. Each provider maps a kind to its native primitive, and MUST reject a kind it cannot honor with UnsupportedContentError (or degrade explicitly, as Baileys maps buttons to numbered text). The template and native kinds are the escape hatches for transport-specific features (Cloud API templates, Discord components, Telegram inline keyboards) without polluting the neutral kinds.

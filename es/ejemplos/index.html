Ejemplos ​

Bots completos para copiar, ejecutar y adaptar. Casi todos los ejemplos son un único archivo bot.js que muestra un conjunto de funciones de botmesh, con una transcripción capturada de una ejecución real y enlaces a la guía de cada función que usa. Un test ejecuta el código de cada ejemplo y comprueba su transcripción, así que lo que lees es lo que obtienes.

Ejecutar cualquier ejemplo ​

  1. Prepara un proyecto una vez, como en Inicio rápido (Node.js 22.12+, "type": "module", npm install @botmesh/core @botmesh/baileys).

  2. Guarda el código del ejemplo como bot.js.

  3. Chatea con él en la terminal, sin teléfono:

    bash
    npx botmesh dev bot.js

  4. Conéctalo de verdad con node bot.js (un QR para WhatsApp), o cambia el provider para Telegram. El código del bot no cambia entre canales.
